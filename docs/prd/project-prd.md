# Project PRD - 라프텔 스토어 QA 자동화

## 1. 프로젝트 목적
커머스 서비스인 라프텔 스토어(https://store.laftel.net/)의 기능을 AI로 Test Case를 생성하고, 생성된 TC를 기반으로 자동화 대상 영역을 선정하여 AI로 자동화용 TC 생성 및 자동화 코드를 생성함으로써 테스트 자동화를 진행한다.

## 2. 대상 서비스 개요
라프텔 스토어는 애니메이션 굿즈를 판매하는 커머스 서비스이며, 모바일 웹 기준으로 설계된 반응형 웹페이지이다.

## 3. 대상 URL / 환경
- Production: https://store.laftel.net/
- 별도 dev/staging 환경 없음, 상용 환경에서만 검증

## 4. 테스트 환경
- PC Web - Chrome (장비 부족으로 PC Chrome에서만 테스트, 모바일 실기기/브라우저 테스트는 미진행)
- 계정 조건: 로그인/비로그인에 따라 동작 다름 — 두 조건 모두 고려 필요. 상세 계정 조건은 Feature PRD 단계에서 기재

## 5. 대상 Feature 목록
(사용자가 PC Chrome으로 직접 조작하며 캡처한 화면을 근거로 정리한 구조 요약이며, 상세 요구사항은 Feature PRD에서 다룹니다.)

### 메인페이지
- 상단: LAFTEL 스토어 로고, 검색창, 검색 아이콘, 장바구니 아이콘
- 상단 배너(캐러셀)
- "인기작 굿즈" 작품별 원형 아이콘 목록
- 다수의 "작품/카테고리별 굿즈 추천" 캐러셀 섹션 반복 배치(IP 테마, TOP 100 순위, 진행중 이벤트, 신규/마감임박 굿즈, 세트 상품 등)
- 상품 카드 공통 구성: 이미지, 찜 아이콘, 작품명, 상품명, 가격(할인율), "예약구매"/"NEW" 뱃지
- 하단 푸터(회사소개/고객센터/공지사항/이용약관/청소년보호정책/개인정보처리방침/저작권 표기/SNS 링크)

### 검색페이지 (검색창 진입 후 기본 화면)
- 뒤로가기, 검색창, "취소" 버튼
- "인기 작품" 아이콘 목록
- "지금 사람들이 많이 구매하는 굿즈" 랭킹 리스트

### 검색 클릭시 (검색어 미입력 + 최근 검색 이력 없음)
- 뒤로가기, 검색창, "취소" 버튼
- 빈 상태 일러스트 + "최근 검색 내역이 없어요" 안내

### 상품상세
- 상품 이미지 캐러셀("1/8" 페이지네이션), "실제 상품과 다를 수 있음" 안내
- 작품명 링크(외부 이동 아이콘), 옵션/상품명, 가격
- 배송정보(배송비/무료배송 기준/발송예정일)
- "같은 작품 굿즈" 추천 캐러셀
- "상세정보" 탭: 정품/예약취소·조기품절/연령제한 안내, 랜덤 단품 "교환·환불 불가" 강조 안내
- 상세정보 하단 아코디언(상품정보 제공고시/교환·반품 안내/판매자 정보/유의사항)
- 하단 고정: 찜 아이콘 + "구매하기" 버튼

### 내 스토어 (로그인 상태 접근 화면)
- "내 스토어" 타이틀, 뒤로가기, 장바구니 아이콘
- 4개 메뉴: 주문내역/쿠폰/찜/문의내역
- "최근 본 상품" 섹션(더보기), "추천 상품" 섹션
- 하단 푸터(메인페이지와 동일)

### 장바구니
- "장바구니" 타이틀, 뒤로가기
- 빈 상태: 일러스트 + "장바구니에 담긴 상품이 아직 없어요" 안내

### 최근 본 상품 (전체 목록 페이지)
- "최근 본 상품" 타이틀, 뒤로가기
- 2열 그리드 상품 카드 나열

## 6. In Scope
검색, 상품상세, 찜, 주문(결제 제외), 카트

## 7. Out of Scope
- 6번(In Scope)에 명시된 항목을 제외한 라프텔 스토어의 모든 기능 및 UI
- 단, In Scope 기능 수행을 위해 메인페이지, 내 스토어 등이 진입점으로 필요한 경우, 그 진입점 목적 범위 내에서는 이용 가능
