# Feature PRD - 카트

## 1. 개요

라프텔 스토어(https://store.laftel.net/)의 장바구니(카트) 화면(`/cart?...`) 기능. 상품상세 등에서
담긴 상품을 화면에 나열하고, 상품 선택(전체선택/개별선택/판매자 그룹 선택), 수량 조절, 개별/일괄/품절
삭제 등 장바구니 화면 자체의 조작을 다룬다. 장바구니 화면에서 "구매하기"를 눌러 주문/결제 화면으로
이동하는 것은 주문 Feature PRD(REQ-ORDER-001)에서 이미 다루므로 본 문서에서는 진입점 언급 수준으로만
참조한다.

## 2. 관련 Project PRD 참조

- 문서: `/docs/prd/project-prd.md`
- 상태: 승인완료 (승인일: 2026-09-03)
- Project PRD 6번(In Scope)에 명시된 "카트" 항목에 해당.
- Project PRD 5번(대상 Feature 목록)의 "장바구니" 항목("장바구니" 타이틀, 뒤로가기, 빈 상태: 일러스트
  + "장바구니에 담긴 상품이 아직 없어요" 안내)이 본 문서 REQ-CART-003, REQ-CART-020과 대응된다.

## 3. 사용자 조작 시나리오

1. 상품상세에서 상품을 담으면 화면 하단에 "장바구니에 상품을 담았어요" 토스트와 "보러가기" 링크가
   노출되고, 이를 클릭하거나 상단 장바구니 아이콘(담긴 상품 개수가 숫자 뱃지로 표시됨)을 클릭하면
   장바구니 화면(`/cart?...`)으로 이동한다. URL로 직접 진입하는 것도 가능하다.
2. 장바구니에 상품이 1개 이상 있을 때, 화면 상단에는 "장바구니" 타이틀과 뒤로가기, 그 아래
   "전체선택 (N/M)" 체크박스와 "품절 삭제"/"삭제" 버튼이 표시된다.
3. 이어서 판매자명("Laftel Store") 그룹 체크박스와 함께 그룹에 속한 상품 카드들이 나열된다. 각
   카드에는 개별 체크박스, 이미지, 작품명(링크), 상품명/옵션명, 수량, 수량 조절(-/+) 컨트롤, 개별
   삭제(X) 아이콘, 상품금액이 표시된다.
4. 목록 하단에는 선택된 상품 건수에 따라 배송비 안내 문구가 달라지며, 그 아래 "결제금액" 섹션(총
   결제금액, 총 상품 금액, 배송비, 상품 할인)과 하단 고정 "{총 결제금액}원 구매하기 (N)" 버튼이
   표시된다.
5. 사용자는 개별 체크박스, 판매자 그룹 체크박스, 최상단 전체선택 체크박스를 통해 선택 상태를
   변경할 수 있으며, 선택 변경 시 상단 카운트와 하단 버튼의 금액/개수가 즉시 갱신된다.
6. 수량 조절(-/+)로 각 상품의 수량을 변경할 수 있으며, 변경 시 해당 상품금액과 총 결제금액이
   실시간으로 갱신된다. 최소 수량(1개) 및 재고 상한에 도달하면 각각의 제약이 적용된다.
7. 개별 삭제(X), 상단 "삭제"(선택 상품 일괄삭제), "품절 삭제"(품절/판매종료 상품 일괄삭제) 액션은
   각각 확인 팝업을 거쳐 진행된다.
8. 장바구니에 담긴 상품이 없으면, 상단 타이틀/뒤로가기만 유지된 채 중앙에 빈 상태 일러스트와
   "장바구니에 담긴 상품이 아직 없어요." 안내 문구가 표시된다.

## 4. Requirements

### 4.1 확인된 요구사항

**진입**
- **REQ-CART-001**: 상품상세 등에서 상품을 담으면 화면 하단에 "장바구니에 상품을 담았어요" 토스트와 "보러가기" 링크가 노출되며, 클릭 시 장바구니 화면으로 이동한다. 이때 상단 장바구니 아이콘에는 담긴 상품 개수가 숫자 뱃지로 표시된다.
- **REQ-CART-002**: 상단 장바구니 아이콘 클릭, URL 직접 진입(`/cart?...`) 등 여러 경로로 장바구니 화면에 진입할 수 있다.

**화면 레이아웃 (상품 1개 이상 있을 때)**
- **REQ-CART-003**: 화면 상단에 "장바구니" 타이틀과 뒤로가기가 표시된다.
- **REQ-CART-004**: 타이틀 아래에 "전체선택 (N/M)" 체크박스와 우측 "품절 삭제"/"삭제" 버튼이 표시된다.
- **REQ-CART-005**: 판매자명(예: "Laftel Store") 그룹 체크박스와 함께, 해당 판매자 그룹에 속한 상품 카드들이 나열된다.
- **REQ-CART-006**: 상품 카드에는 개별 체크박스, 이미지, 작품명(링크), 상품명/옵션명(옵션이 있는 경우 "옵션: {옵션명} | {수량}개" 형식), "상품 구매 수량: N개" 표시, 수량 조절(-/N/+), 개별 삭제(X) 아이콘, "상품금액"이 표시된다.
- **REQ-CART-007**: 상품 목록 하단에 배송비 안내가 표시되며, 선택된 상품이 2건 이상이면 "N건 묶음배송비 무료" 문구가, 1건이면 해당 상품의 개별 배송비 정책 문구(예: "배송비 3,000원 (100,000원 이상 무료배송)")가 노출된다.
- **REQ-CART-008**: "결제금액" 섹션에는 총 결제금액(강조), 총 상품 금액, 배송비, 상품 할인이 표시된다.
- **REQ-CART-009**: 화면 하단에 "{총 결제금액}원 구매하기 (N)" 버튼이 고정 노출되며, N은 선택된 상품의 종류(카드) 수를 의미한다.
- **REQ-CART-010**: 장바구니 상품 카드에는 찜 아이콘(하트)이 표시되지 않는다.

**선택 동작**
- **REQ-CART-011**: 개별 상품 체크박스를 해제/선택하면 상단 "전체선택 (N/M)" 표시와 하단 "구매하기" 버튼의 금액/개수가 즉시 갱신된다.
- **REQ-CART-012**: 판매자 그룹 체크박스를 클릭하면 해당 그룹에 속한 상품 전체가 한 번에 선택 또는 해제된다(토글 동작).
- **REQ-CART-013**: 최상단 "전체선택" 체크박스를 클릭하면 장바구니 내 전체 상품이 한 번에 선택 또는 해제된다.

**수량 조절**
- **REQ-CART-014**: 수량 -/+ 버튼 클릭 시 해당 상품의 "상품금액"과 하단 총 결제금액이 실시간으로 갱신된다.
- **REQ-CART-015**: 수량이 1개일 때 "-" 버튼은 비활성화되며, 클릭해도 수량이 줄거나 삭제 확인 팝업이 뜨지 않는다.
- **REQ-CART-016**: 재고 상한에 도달한 상태에서 "+" 버튼을 클릭하면 "재고부족. 잔여재고 N개" 토스트 메시지가 노출되고 수량은 더 이상 증가하지 않는다.

**삭제**
- **REQ-CART-017**: 개별 상품의 X(삭제) 버튼을 클릭하면 "선택한 상품을 삭제하시겠어요?" 확인 팝업(취소/삭제)이 노출되며, "삭제"를 누르면 해당 상품만 삭제되고 "취소"를 누르면 팝업만 닫힌다.
- **REQ-CART-018**: 상단 "삭제" 버튼(체크된 상품 일괄삭제)을 클릭하면 REQ-CART-017과 동일한 문구("선택한 상품을 삭제하시겠어요?")의 확인 팝업이 노출되며, "삭제"를 누르면 체크(선택)된 상품 전체가 한꺼번에 삭제된다.
- **REQ-CART-019**: "품절 삭제" 버튼을 클릭하면 "품절 혹은 판매종료된 상품을 모두 삭제하시겠어요?" 확인 팝업(취소/삭제)이 노출된다. (단, "삭제" 클릭 이후 실제로 어떤 상품이 삭제되는지의 결과는 4.2 참조 — 검증 범위에서 재현하지 못해 미확인)

**빈 장바구니**
- **REQ-CART-020**: 장바구니에 담긴 상품이 없으면 상단 "장바구니" 타이틀/뒤로가기는 유지된 채, 중앙에 빈 상태 일러스트와 "장바구니에 담긴 상품이 아직 없어요." 안내 문구만 표시되고 별도의 CTA 버튼은 없다.

**구매하기(선택 0건)**
- **REQ-CART-021**: 장바구니에 상품이 1개 이상 있으나 선택된 상품이 0건인 상태(전체선택 "0/M")에서 하단 "{총 결제금액}원 구매하기 (0)" 버튼을 클릭하면 "구매할 상품을 선택해주세요." 안내 팝업이 노출된다. 팝업의 "확인" 버튼을 클릭하면 팝업이 닫히고 장바구니 화면이 그대로 유지되며, 결제 페이지로는 진행되지 않는다.

### 4.2 미확인 / 추가 확인 필요 항목

- 품절/판매종료 상품이 장바구니에 담겨 있을 때의 실제 표시 방식(뱃지/문구 유무), 체크박스 선택 가능 여부, 수량 조절 가능 여부 — 상용 환경 특성상 해당 상태를 재현할 수 없어 검증 범위에서 확인하지 못함
- "품절 삭제" 확인 팝업에서 "삭제"를 클릭한 이후 실제로 어떤 상품이 삭제되는지(품절/판매종료 상품만 정확히 골라 삭제되는지) — 팝업 노출까지만 확인, 실제 삭제 동작 자체는 미확인
- 상품별 재고 수량 상한의 정확한 값 — 상품마다 상이하여 특정 수치를 요구사항으로 고정하기 어려움(패턴만 확인됨)

## 5. Feature 단위 In Scope / Out of Scope

**In Scope**
- 장바구니 화면(`/cart?...`) 진입(여러 경로 공통)
- 상품이 1개 이상 있을 때의 화면 레이아웃(타이틀, 전체선택/품절삭제/삭제, 판매자 그룹, 상품 카드 구성, 배송비 안내, 결제금액 요약, 하단 고정 구매하기 버튼)
- 전체선택/판매자 그룹 선택/개별 선택 동작
- 수량 조절(-/+) 및 그에 따른 금액 실시간 갱신, 최소 수량/재고 상한 제약
- 개별 삭제, 선택 상품 일괄 삭제, 품절 삭제(확인 팝업 노출까지)
- 빈 장바구니 상태 화면

**Out of Scope**
- 장바구니 화면에서 "구매하기" 클릭 이후의 주문/결제 프로세스 — 주문 Feature PRD 범위
- 품절/판매종료 상품이 장바구니에 있을 때의 실제 표시/선택/삭제 결과 — 재현 불가로 4.2에 미확인 항목으로 남김(향후 별도 확인 필요)
- 쿠폰 적용, 결제수단 선택 등 결제금액에 영향을 주는 그 외 요소 — 주문 Feature PRD 범위
- 로그인/회원 계정 관리 기능 자체

## 6. 예외 / 에러 케이스

- 수량 1개 상태에서 "-" 클릭 시 아무 동작 없음(비활성화) (REQ-CART-015)
- 재고 상한 도달 후 "+" 클릭 시 "재고부족. 잔여재고 N개" 토스트 노출, 수량 증가 차단 (REQ-CART-016)
- 개별 삭제/일괄 삭제 시 확인 팝업을 거쳐야 실제 삭제가 진행됨, "취소" 시 삭제되지 않음 (REQ-CART-017, REQ-CART-018)
- "품절 삭제" 시 일반 삭제와 다른 문구의 확인 팝업 노출 (REQ-CART-019)
- 선택된 상품이 0건인 상태에서 "구매하기" 클릭 시 "구매할 상품을 선택해주세요." 안내 팝업 노출, "확인" 클릭 시 장바구니 화면 유지(결제 페이지로 미진행) (REQ-CART-021)

## 7. 비고

- 장바구니 화면에서 "구매하기"를 클릭해 주문/결제 화면(`/check-out/{uuid}`)으로 이동하는 동작은
  주문 Feature PRD(REQ-ORDER-001)에서 이미 확인되었으므로 본 문서에서는 중복 서술하지 않았다.
- 품절/판매종료 상품의 장바구니 내 표시·선택·삭제 결과는 상품상세 Feature PRD에서 정의한 상품
  상태(판매중/예약구매/판매종료/품절)와 연관될 수 있으나, 상용 환경에서 해당 상태를 인위적으로
  재현할 수 없어 이번 검증 범위에서 다루지 못했다(4.2 참조). 이는 Production 데이터를 사용자
  승인 없이 임의로 조작하지 않는다는 원칙에 따른 것이기도 하다.
- 배송비 관련 문구는 선택된 상품 건수(1건/2건 이상)에 따라 달라지는 것으로 확인되었으며, 항상
  무료라고 서술하지 않도록 REQ-CART-007에 조건을 명시했다.
