# Feature PRD - 검색

## 1. 개요

라프텔 스토어(https://store.laftel.net/)의 검색 기능. 메인페이지 상단 검색창(또는 `/search`
직접 진입)을 통해 검색페이지로 이동하며, 검색어 입력 시 자동완성/추천 검색어를 제공하고,
검색 실행 시 결과 목록(작품 정보, 정렬, 상품 그리드)을 노출한다. 검색어가 없는 상태에서는
최근 검색어 목록을 관리(조회/개별 삭제/전체 삭제)할 수 있다.

## 2. 관련 Project PRD 참조

- 문서: `/docs/prd/project-prd.md`
- 상태: 승인완료 (승인일: 2026-09-03)
- Project PRD 6번(In Scope)에 명시된 "검색" 항목에 해당.

## 3. 사용자 조작 시나리오

1. 메인페이지 상단 검색창(또는 검색 아이콘)을 클릭하면 검색페이지(`/search`)로 이동한다.
   `/search` URL로 직접 진입도 가능하다.
2. 검색창에 검색어를 입력하면 자동완성/추천 검색어가 노출된다. 입력 중 텍스트를 수정하거나
   일부 삭제하면 그에 맞게 자동완성/추천 검색어가 실시간으로 갱신되고, 완전히 삭제하면
   최근 검색어 목록이 노출된다.
3. 자동완성의 "작품" 뱃지 항목을 클릭하면 해당 작품 페이지(`/ip/{id}`)로 이동하고, 뱃지 없는
   연관 검색어 텍스트를 클릭하면 그 텍스트로 검색이 실행되어 일반 검색 결과 화면
   (`/search?keyword=...`)으로 이동한다.
4. 검색을 실행(엔터 등)하면 검색 결과 화면에 관련 작품 정보, 결과 총 개수, 정렬 드롭다운,
   상품 그리드가 표시된다.
5. 결과가 없는 검색어를 입력하면 빈 상태 일러스트와 안내 문구가 표시된다.
6. 최근 검색어 목록에서 항목을 클릭해 재검색하거나, "X"로 개별 삭제, "모두 삭제"로 전체
   삭제할 수 있다.
7. "뒤로가기"를 누르면 검색페이지 진입 이전 화면으로, "취소"를 누르면 검색페이지 초기
   화면(인기 작품 아이콘 + 랭킹 리스트)으로 이동한다.

## 4. Requirements

### 4.1 확인된 요구사항

**검색 진입**
- **REQ-SEARCH-001**: 메인페이지 상단 검색창(또는 검색 아이콘)을 클릭하면 검색페이지(`/search`)로 이동한다.
- **REQ-SEARCH-002**: `/search` URL로 직접 진입할 수 있다.

**자동완성/추천 검색어**
- **REQ-SEARCH-003**: 검색어 입력 시 자동완성/추천 검색어가 노출된다.
- **REQ-SEARCH-004**: 자동완성 목록은 상단에 "작품" 뱃지가 붙은 관련 작품 목록, 하단에 뱃지 없는 연관 검색어(구체적 상품/키워드 텍스트) 목록으로 구성된다.
- **REQ-SEARCH-005**: 자동완성 노출 개수는 작품 목록 최대 20개, 연관 검색어 최대 10개다.
- **REQ-SEARCH-006**: 영문 키 입력이 한글 자모로 매핑되어도(예: "원" ↔ "dnjs") 동일한 자동완성/추천 검색어가 노출되며, 이는 다른 키워드 조합에서도 동일하게 확인되었다.
- **REQ-SEARCH-007**: 자동완성의 "작품" 뱃지 항목을 클릭하면 해당 작품 페이지(`/ip/{id}`)로 이동하며, 해당 화면에는 배너 이미지, 작품명, 결과 총 개수, "인기순" 정렬 드롭다운, 상품 그리드가 표시된다.
- **REQ-SEARCH-008**: 자동완성의 뱃지 없는 연관 검색어 텍스트를 클릭하면 그 텍스트로 검색이 실행되어 일반 검색 결과 화면(`/search?keyword=...`)으로 이동한다(작품 페이지가 아님).

**검색 결과 화면**
- **REQ-SEARCH-009**: 검색을 실행하면 관련 상품이 검색 결과 화면에 노출된다.
- **REQ-SEARCH-010**: 검색 결과 화면 상단에는 해당 작품 카드(">" 이동 화살표 포함, 클릭 시 작품 페이지로 이동), "총 N개" 결과 개수, "인기순" 정렬 드롭다운이 표시되고, 이후 2열 그리드로 상품 카드가 나열된다.
- **REQ-SEARCH-011**: "총 N개" 표시는 해당 검색어에 대한 상품 개수 기준이다.
- **REQ-SEARCH-012**: 정렬 드롭다운에는 "인기순", "최신순" 2개 옵션과 하단 "취소" 버튼이 있으며, 현재 선택된 정렬에 체크 표시가 된다.
- **REQ-SEARCH-013**: "상품종료" 상태인 상품도 검색 결과 목록에 일반 상품과 함께 노출되며 별도로 숨겨지지 않는다.
- **REQ-SEARCH-014**: "판매종료" 또는 "품절" 상품 클릭 시 상품상세로 정상 진입되며, 상세 화면 하단 구매 버튼 영역은 "구매하기"(활성) 대신 판매종료 상품은 "판매종료" 텍스트, 품절 상품은 "품절" 텍스트의 비활성화(회색조) 버튼으로 각각 표시되고, 찜 아이콘은 두 경우 모두 활성 상태로 유지된다.

**검색 결과 없음**
- **REQ-SEARCH-015**: 결과가 없는 검색어 입력 시, 빈 상태 일러스트와 "앗! 원하시는 검색 결과가 없어요." 안내 문구가 표시된다.
- **REQ-SEARCH-016**: 검색어에 공백만 입력하면 검색이 실행되지 않으며, 별도의 안내 문구도 표시되지 않는다.
- **REQ-SEARCH-017**: 특수문자만 입력했을 때, 매핑되는 자동완성/연관 검색어·작품이 있으면 그것이 노출되고, 매핑되는 것이 없으면 검색어 미입력과 동일하게 결과 없음 화면이 노출된다.
- **REQ-SEARCH-018**: 검색어 최소 글자 수는 1자 이상이다.

**최근 검색어**
- **REQ-SEARCH-019**: 검색어를 완전히 삭제(또는 빈 상태로 재진입)하면 "최근 검색" 타이틀 + 우측 "모두 삭제" 링크, 그 아래 키워드 목록(각 항목 우측 "X" 개별 삭제 아이콘)이 세로로 나열된다.
- **REQ-SEARCH-020**: 검색어 입력 중 텍스트를 수정/삭제하면 그 키워드에 맞는 자동완성/추천 검색어가 실시간으로 갱신된다.
- **REQ-SEARCH-021**: "모두 삭제" 및 개별 "X" 삭제는 별도 확인 팝업/문구 없이 즉시 삭제된다.
- **REQ-SEARCH-022**: 최근 검색어 목록의 키워드 항목을 클릭하면 해당 키워드로 재검색이 실행된다.
- **REQ-SEARCH-023**: 비로그인 상태에서도 최근 검색어가 동일하게 저장/노출된다.

**검색 종료/취소**
- **REQ-SEARCH-024**: "뒤로가기" 버튼 클릭 시 검색페이지 진입 이전 화면(메인페이지에서 진입했으면 메인페이지, 상품상세에서 진입했으면 상품상세)으로 이동한다.
- **REQ-SEARCH-025**: "취소" 버튼 클릭 시 검색창이 빈 placeholder 상태("굿즈 또는 작품명으로 검색해 보세요")로 초기화되고, 검색페이지 초기 화면("인기 작품" 아이콘 목록 + "지금 사람들이 많이 구매하는 굿즈" 랭킹 리스트)으로 이동한다.

**검색 결과 페이지 vs 작품 페이지 결과 집계 기준**
- **REQ-SEARCH-026**: 검색 결과 페이지(`/search?keyword=...`)는 검색어와 텍스트가 매칭되는
  상품 전체를 노출하고, 작품 페이지(`/ip/{id}`)는 해당 작품에 공식적으로 연결(태그)된 상품만
  노출한다. 따라서 동일 키워드(예: "원피스")로 진입하더라도 검색 결과 페이지의 결과 개수
  (119개)와 작품 페이지의 결과 개수(117개)가 서로 다를 수 있다.

### 4.2 미확인 / 추가 확인 필요 항목

- **사용자 추정(미확정)**: 최근 검색어는 100개까지 확인되었으나, 저장 개수 상한선이 실제로 없는지는 추정이며 확정되지 않았다.
- **사용자 추정(미확정)**: 검색어 최대 글자 수 제한, 특수문자/금칙어 제한이 없는 것으로 추정되나 확정되지 않았다.
- **사용자 추정(미확정)**: 비로그인/로그인 상태 간 최근 검색어는 기기(브라우저) 단위로 공유되는 것으로 추정되며, 계정 연동 여부까지 확정된 것은 아니다.

## 5. Feature 단위 In Scope / Out of Scope

**In Scope**
- 검색 진입(검색창 클릭, `/search` 직접 진입)
- 자동완성/추천 검색어 노출 및 클릭 동작
- 검색 실행 및 결과 화면(작품 카드, 결과 개수, 정렬, 상품 그리드)
- 검색 결과 없음 화면
- 최근 검색어 조회/재검색/개별 삭제/전체 삭제
- 검색 종료(뒤로가기/취소) 동작
- 검색 입력값 관련 동작(공백, 특수문자, 최소 글자 수)

**Out of Scope**
- 자동완성/검색결과에서 진입하는 작품 페이지(`/ip/{id}`) 자체의 상세 기능(진입 여부/화면 구성 확인 범위 내에서만 다룸)
- 검색 결과에서 진입하는 상품상세 페이지 자체의 상세 기능(별도 Feature PRD에서 다룸)
- 로그인/회원 계정 관리 기능 자체

## 6. 예외 / 에러 케이스

- 결과가 없는 검색어 입력 시 빈 상태 일러스트 + 안내 문구 노출 (REQ-SEARCH-015)
- 공백만 입력 시 검색 미실행, 별도 안내 없음 (REQ-SEARCH-016)
- 특수문자만 입력 시 매핑 여부에 따라 노출/결과없음 화면 분기 (REQ-SEARCH-017)
- 검색어 최소 글자 수 1자 이상 (REQ-SEARCH-018)
- "상품종료" 상품의 결과 노출 및 상세 진입 시 구매 버튼 비활성화 처리 (REQ-SEARCH-013, REQ-SEARCH-014)

**⚠ 확인된 이상 동작 (마이너, 이슈 의심)**

검색창에 "?" 또는 "*"만 입력하면(매핑되는 검색어가 없음에도 불구하고) 결과 없음 화면이
노출되지 않고, 가나다순으로 정렬된 것으로 보이는 전체 작품 목록(작품 뱃지, 최대 20개)과
연관 검색어로 보이는 상품명 텍스트(최대 10개)가 노출된다. "?" 케이스에서는 URL이
`/search?keyword=%23`("#" 문자로 디코딩됨)로 표시되어, 실제 입력한 "?"와 URL에 반영된
문자가 달라 프론트엔드의 URL 인코딩 처리 이슈로 추정된다. "*" 입력에서도 동일한 이상
동작이 재현되었다. 사용자가 이상 동작으로 명시적으로 기록을 요청한 항목이며, Requirement로
확정하지 않고 별도 이슈 의심 사항으로 기록한다.

  진행하지 않는다.
