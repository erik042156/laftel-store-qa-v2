# Feature PRD - 상품상세

## 1. 개요

라프텔 스토어(https://store.laftel.net/)의 상품상세 기능. 메인페이지 배너/상품 리스트, 내 스토어
(찜/최근 본 상품/추천 상품, 주문내역), 장바구니 등 다양한 경로 또는 `/products/{id}` URL 직접
진입을 통해 접근하며, 이미지 캐러셀, 작품명/상품명/가격, 배송정보, 같은 작품 굿즈 추천,
상세정보 탭 및 아코디언, 하단 고정 찜/구매 영역으로 구성된다. 상품 상태(판매중/예약구매/
판매종료/품절)와 옵션 유무, 로그인 여부에 따라 화면 동작이 달라진다.

## 2. 관련 Project PRD 참조

- 문서: `/docs/prd/project-prd.md`
- 상태: 승인완료 (승인일: 2026-09-03)
- Project PRD 6번(In Scope)에 명시된 "상품상세" 항목에 해당.

## 3. 사용자 조작 시나리오

1. 메인페이지 배너, 메인페이지 상품 리스트, 내 스토어(찜한 상품/최근 본 상품/추천 상품, 찜 메뉴,
   주문내역), 장바구니에 담긴 상품 클릭 등 다양한 경로로 상품상세 화면에 진입하거나,
   `/products/{id}` URL로 직접 진입한다. 존재하지 않거나 게시 종료된 상품 번호로 접근하면
   커스텀 404 에러 페이지가 노출된다.
2. 진입 시 상단 바(뒤로가기/검색/장바구니 아이콘), 이미지 캐러셀, 작품명/상품명/가격, 배송정보,
   "같은 작품 굿즈" 추천 캐러셀, "상세정보" 탭, 아코디언, 하단 고정 찜/구매 버튼이 순서대로
   노출된다.
3. 이미지 캐러셀을 좌우로 넘겨 여러 장의 상품 이미지를 순환 구조로 확인할 수 있으며, 페이지네이션
   숫자도 함께 갱신된다.
4. 작품명 링크, 배송정보 안내 아이콘, 같은 작품 굿즈 카드/더보기, 상세정보 탭 하단 아코디언
   항목을 클릭하면 각각 정해진 동작(작품 페이지 이동, 안내 팝업, 관련 상품 페이지 이동, 별도 정보
   페이지 이동)이 수행된다.
5. 하단 찜 아이콘을 클릭하면 로그인 여부에 따라 로그인 유도 팝업 또는 찜 추가/해제 처리가
   이루어진다. "같은 작품 굿즈" 캐러셀 카드 위의 찜 아이콘도 동일하게 그 자리에서 찜 처리된다.
6. 하단 "구매하기"(또는 상품 상태별 버튼)를 클릭하면 같은 화면 내에서 옵션 선택(있는 경우) →
   수량선택(최소 1개) → 총 금액 → 장바구니/바로구매 버튼 영역이 확장 노출된다.
7. 상품 상태는 판매중/예약구매/판매종료/품절 4가지로 구분되며, 상태에 따라 하단 버튼의 텍스트와
   활성화 여부가 달라진다.

## 4. Requirements

### 4.1 확인된 요구사항

**진입 경로**
- **REQ-PRODUCT-DETAIL-001**: 메인페이지 최상단 배너의 상품상세로 랜딩되는 상품을 클릭하면 상품상세 화면으로 진입한다.
- **REQ-PRODUCT-DETAIL-002**: 메인페이지 내 상품 리스트의 임의의 상품을 클릭하면(페이지 내 이동) 상품상세 화면으로 진입한다.
- **REQ-PRODUCT-DETAIL-003**: 내 스토어의 찜한 상품/최근 본 상품/추천 상품에서 상품을 클릭하면 상품상세 화면으로 진입한다.
- **REQ-PRODUCT-DETAIL-004**: 내 스토어 > 찜 > 찜한 상품/작품에서 상품을 클릭하면 상품상세 화면으로 진입한다.
- **REQ-PRODUCT-DETAIL-005**: 장바구니에 담긴 상품을 클릭하면 상품상세 화면으로 진입한다.
- **REQ-PRODUCT-DETAIL-006**: `https://store.laftel.net/products/{상품번호}` URL로 상품상세 화면에 직접 진입할 수 있다.
- **REQ-PRODUCT-DETAIL-007**: 존재하지 않거나 게시 종료된 상품 번호(예: `/products/2`)로 진입하면 커스텀 404 에러 페이지("이런, 이미 사라진 페이지군요." 안내 + "삭제된 페이지거나 잘못된 주소입니다. 라프텔 홈으로 이동해 주세요. 아니면, 함께 범인을 찾아볼까요?" 문구 + "홈으로 이동" 버튼 + "범인 찾아보기" 링크)가 노출된다.
- **REQ-PRODUCT-DETAIL-008**: 내 스토어 > 주문내역(`/orders`)에서 주문 상품을 클릭하면 상품상세 화면으로 진입한다.

**상단 영역**
- **REQ-PRODUCT-DETAIL-009**: 상품상세 화면 상단에 뒤로가기("<"), 검색 아이콘, 장바구니 아이콘(담긴 수량 뱃지)이 표시된다.
- **REQ-PRODUCT-DETAIL-010**: 검색 아이콘 클릭 시 검색페이지(`/search`)로 이동한다.
- **REQ-PRODUCT-DETAIL-011**: 장바구니 아이콘 클릭 시 장바구니 페이지(`/cart?log_cart_entry_point=app_bar_cart_icon`)로 이동한다.
- **REQ-PRODUCT-DETAIL-012**: 뒤로가기 클릭 시 상품상세 진입 이전 화면으로 이동하며, 이전 화면은 진입 경로에 따라 달라진다.

**이미지 캐러셀**
- **REQ-PRODUCT-DETAIL-013**: 상품 이미지 캐러셀에 "N/M" 형식의 페이지네이션이 표시되며, 좌우로 넘겨 사진을 전환할 수 있다.
- **REQ-PRODUCT-DETAIL-014**: 첫 번째 사진에서 좌→우로 넘기면 마지막 사진이, 마지막 사진에서 우→좌로 넘기면 첫 번째 사진이 노출되는 순환 구조로 동작한다.
- **REQ-PRODUCT-DETAIL-015**: 사진 전환 시 페이지네이션 숫자도 함께 갱신된다(예: "1/4" → "2/4").

**상품 정보**
- **REQ-PRODUCT-DETAIL-016**: 작품명(예: "원피스 >")과 외부 이동 아이콘이 표시되며, 클릭 시 같은 창(탭)에서 해당 작품 페이지로 이동한다.
- **REQ-PRODUCT-DETAIL-017**: 이미지 캐러셀 아래에 상품명과 가격이 표시된다.

**배송정보**
- **REQ-PRODUCT-DETAIL-018**: 배송정보 섹션에 배송비, 무료배송 기준, 발송예정일이 표시된다.
- **REQ-PRODUCT-DETAIL-019**: 발송예정 안내 아이콘(ⓘ) 클릭 시 "발송예정 안내" 팝업(배송 일정은 영업일 기준이라는 안내, 판매사/택배사/상품 준비 상황에 따라 발송 예정일이 달라질 수 있다는 안내 + "확인" 버튼)이 노출된다.

**같은 작품 굿즈**
- **REQ-PRODUCT-DETAIL-020**: "같은 작품 굿즈" 캐러셀에 개별 상품 카드(이미지, 찜 아이콘, 가격, "예약구매"/"NEW" 등 뱃지)가 나열된다.
- **REQ-PRODUCT-DETAIL-021**: "같은 작품 굿즈" 카드를 클릭하면 해당 상품의 상품상세 페이지로 이동한다.
- **REQ-PRODUCT-DETAIL-022**: "더보기" 클릭 시 같은 작품 굿즈 전용 목록 페이지(`/products/{id}/related`, 상단 "같은 작품 굿즈" 타이틀 + 뒤로가기 + 장바구니 아이콘, 2열 그리드)로 이동한다.

**상세정보 탭**
- **REQ-PRODUCT-DETAIL-023**: "상세정보" 탭에 안내 박스와 상품 상세 이미지 배너가 노출된다.
- **REQ-PRODUCT-DETAIL-024**: 상세정보 탭의 안내 박스/본문 내용은 상품마다 상이하며, 안내 박스의 문구는 어드민이 상품별로 직접 셋팅하는 것으로 추정된다(랜덤/비랜덤 등 상품 유형에 따라 시스템적으로 분기되는 것은 아닌 것으로 보인다). 예를 들어 실제 확인된 한 사례로, 일반 상품은 정품 안내/예약 상품 최소 수량 미충족 시 주문 취소 가능 안내/연령 제한 안내 3개 항목으로 구성되어 있었고, 한 랜덤 단품에서는 이에 더해 "<구매 전 유의사항> 반드시 읽어주세요 — 상품 1개당 랜덤 1종 발송, 선택 불가, 중복 시 교환·환불 불가" 문구가 파란색으로 강조되어 추가 표시되어 있었다.
- **REQ-PRODUCT-DETAIL-025**: "상세정보 더보기" 토글을 클릭하면 하단에 숨겨져 있던 상세 이미지/설명이 펼쳐진다.

**아코디언**
- **REQ-PRODUCT-DETAIL-026**: 상세정보 탭 하단에 3개 아코디언 항목(상품정보 제공고시/판매자 정보/유의사항)이 있으며, 각 항목 클릭 시 별도 페이지로 이동한다.
- **REQ-PRODUCT-DETAIL-027**: "상품정보 제공고시"(`/products/{id}/product-info`)는 브랜드/원산지/출시일/제조사/공급사/자체분류를 표 형태로 표시한다.
- **REQ-PRODUCT-DETAIL-028**: (삭제됨 — 실제 사이트에서 "교환/반품 안내" 아코디언 항목 자체가 제거되어 범위에서 제외. 결번으로 유지, 2026-09-14)
- **REQ-PRODUCT-DETAIL-029**: "판매자 정보"(`/products/{id}/seller-info`)는 공급사 정보를 표시한다.
- **REQ-PRODUCT-DETAIL-030**: "유의사항"(`/products/{id}/notice`)은 배송 안내(발송 지연 가능성, 배송지 변경 제한, 예약 상품 합배송 미지원 등)와 주문 취소 및 환불 안내(자동 취소 조건, 일반/예약 상품별 취소 가능 시점, 환불 가능 기간)를 표시한다.

**푸터**
- **REQ-PRODUCT-DETAIL-031**: 아코디언 하단에 라프텔 공통 푸터(사업자 정보, 회사소개/고객센터/공지사항/이용약관/청소년보호정책/개인정보처리방침/저작권 표기, SNS 링크)가 노출된다.

**하단 고정 찜/구매 영역**
- **REQ-PRODUCT-DETAIL-032**: 화면 하단에 찜(하트) 아이콘과 상태별 버튼이 스크롤 위치와 무관하게 고정 노출된다.
- **REQ-PRODUCT-DETAIL-033**: 비로그인 상태에서 찜 아이콘을 클릭하면 "로그인 후 이용해 주세요." 팝업(취소/로그인 버튼)이 노출되며, 찜 처리는 되지 않는다.
- **REQ-PRODUCT-DETAIL-034**: 로그인 상태에서 찜 아이콘을 클릭하면 "찜한 상품에 추가했어요" 토스트 메시지가 노출되고, 하트 아이콘이 빈 하트에서 채워진 보라색 하트로 변경된다.
- **REQ-PRODUCT-DETAIL-035**: "구매하기" 버튼을 클릭하면 별도 페이지 이동 없이 같은 화면 하단에 옵션 선택(있는 경우)/수량선택/총 금액/장바구니·바로구매 버튼 영역이 확장 노출된다.
- **REQ-PRODUCT-DETAIL-036**: 옵션이 있는 상품은 "구매하기" 클릭 시 옵션 선택 드롭다운이 먼저 펼쳐지며, 품절된 옵션은 회색 처리 및 "품절" 라벨로 선택 불가능하게 표시되고, 선택 가능한 옵션은 정상 노출된다.
- **REQ-PRODUCT-DETAIL-037**: 옵션 선택 후 드롭다운이 닫히고 선택된 옵션명, 수량선택 UI, 옵션별 가격이 표시되며, "총 금액"도 선택한 옵션 가격 기준으로 갱신된다.
- **REQ-PRODUCT-DETAIL-038**: 옵션이 없는 상품은 옵션 선택 단계 없이 "구매하기" 클릭 시 바로 수량선택 UI만 노출된다.
- **REQ-PRODUCT-DETAIL-039**: 하단 구매 영역의 수량선택 UI에서 선택 가능한 최소 수량은 1개이다(최대 수량은 상품마다 상이하여 특정하지 않음).
- **REQ-PRODUCT-DETAIL-048**: 하단 찜 아이콘을 재클릭하면 찜이 취소된다(토글 동작).
- **REQ-PRODUCT-DETAIL-049**: "같은 작품 굿즈" 캐러셀 카드 위의 찜 아이콘을 클릭하면 카드 클릭(상세 페이지 이동)과 별개로 그 자리에서 찜 처리가 이루어지며, "찜한 상품에 추가했어요" 토스트 노출과 하트 아이콘 보라색 변경이 동일하게 적용된다.

**상품 상태별 하단 버튼**
- **REQ-PRODUCT-DETAIL-040**: 상품 상태는 판매중/예약구매/판매종료/품절 4가지로 구분되며, 상태에 따라 하단 버튼의 텍스트와 활성화 여부가 다르게 표시된다.
- **REQ-PRODUCT-DETAIL-041**: 판매중 상태의 상품은 하단 버튼이 "구매하기" 텍스트로 활성화(보라색)되어 표시된다.
- **REQ-PRODUCT-DETAIL-042**: 예약구매 상태의 상품은 이미지 영역과 하단 버튼에 "예약 마감까지 D일 HH:MM" 형식의 실시간 카운트다운이 표시되며, 버튼 텍스트는 "예약구매"(활성, 보라색)로 표시된다.
- **REQ-PRODUCT-DETAIL-043**: 품절 상태의 상품은 하단 버튼이 "품절" 텍스트의 비활성화(회색조) 버튼으로 표시되며, 찜 아이콘은 활성 상태로 유지된다.
- **REQ-PRODUCT-DETAIL-044**: 판매종료 상태의 상품은 하단 버튼이 "판매종료" 텍스트의 비활성화(회색조) 버튼으로 표시되며, 찜 아이콘은 활성 상태로 유지된다.
- **REQ-PRODUCT-DETAIL-045**: 품절/판매종료 등 비활성화된 버튼을 클릭해도 아무 동작이 일어나지 않는다.

**로그인 여부**

- **REQ-PRODUCT-DETAIL-047**: 찜 동작(로그인 유도 팝업 여부) 관련 차이를 제외하면, 로그인/비로그인 상태 간 상품상세 화면 자체의 구성 차이는 없다.

## 5. Feature 단위 In Scope / Out of Scope

**In Scope**
- 상품상세 진입(다양한 경로 및 URL 직접 진입, 존재하지 않는 상품 접근 시 에러 페이지)
- 상단 바(뒤로가기/검색/장바구니 아이콘) 동작
- 이미지 캐러셀 조작
- 작품명/상품명/가격, 배송정보 노출 및 안내 팝업
- "같은 작품 굿즈" 추천 캐러셀 및 더보기 목록 이동
- 상세정보 탭(안내 박스, 상품 유형별 상이한 내용, 더보기 토글) 및 하단 아코디언 3개 항목
- 하단 고정 찜/구매 영역(찜 추가/해제 동작, 옵션·수량 선택 UI 노출, 상품 상태별 버튼 표시)
- 로그인/비로그인에 따른 동작 차이(찜, 최근 본 상품 기록)

**Out of Scope**
- 결제/주문 프로세스 자체("장바구니"/"바로구매" 버튼 클릭 이후의 결제 화면, Project PRD상 결제는 Out of Scope)
- 검색, 장바구니, 찜 목록 등 다른 Feature 자체의 상세 기능(상품상세로의 진입점 목적 범위 내에서만 다룸)
- 작품 페이지(`/ip/{id}`) 자체의 상세 기능
- 로그인/회원 계정 관리 기능 자체

## 6. 예외 / 에러 케이스

- 존재하지 않거나 게시 종료된 상품 URL 접근 시 커스텀 404 에러 페이지 노출 (REQ-PRODUCT-DETAIL-007)
- 비로그인 상태에서 찜 클릭 시 로그인 유도 팝업, 찜 미처리 (REQ-PRODUCT-DETAIL-033)
- 옵션 상품 중 품절된 옵션은 선택 불가 처리 (REQ-PRODUCT-DETAIL-036)
- 품절/판매종료 상품의 비활성화된 하단 버튼 클릭 시 무반응 (REQ-PRODUCT-DETAIL-045)
