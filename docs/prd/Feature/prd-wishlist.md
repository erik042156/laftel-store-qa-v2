# Feature PRD - 찜

## 1. 개요

라프텔 스토어(https://store.laftel.net/)의 찜 기능. 메인페이지, 검색페이지, 작품 연관
상품리스트 페이지(`/ip/{id}`), 상품상세, 내 스토어(`/my`)의 상품 카드에 공통으로 노출되는
찜(하트) 아이콘을 통해 로그인 사용자가 상품을 찜 목록에 추가/해제할 수 있다. 내 스토어 >
찜(`/my/wish`)에서는 "상품"/"작품" 2개 탭으로 찜 목록을 조회하며, "상품" 탭에서는 편집
모드를 통한 다중 선택 삭제를, "작품" 탭에서는 작품 단위 또는 개별 상품 단위의 찜 해제를
지원한다. 비로그인 상태에서는 찜 관련 기능 접근 시 로그인 유도 팝업이 노출된다.

## 2. 관련 Project PRD 참조

- 문서: `/docs/prd/project-prd.md`
- 상태: 승인완료 (승인일: 2026-09-03)
- Project PRD 6번(In Scope)에 명시된 "찜" 항목에 해당.

## 3. 사용자 조작 시나리오

1. 메인페이지, 검색페이지, 작품 연관 상품리스트 페이지(`/ip/{id}`), 상품상세, 내 스토어의
   상품 카드에 공통으로 노출되는 찜 아이콘을 클릭하면, 로그인 상태에서는 찜 처리(토스트 노출,
   하트 색상 변경)가, 비로그인 상태에서는 로그인 유도 팝업이 노출된다. 찜 아이콘은 재클릭 시
   토글 방식으로 찜이 해제된다.
2. 내 스토어(`/my`) 상단 4개 메뉴 중 "찜" 메뉴에는 찜한 상품 개수가 숫자 뱃지로 표시되며,
   "찜한 상품"/"최근 본 상품" 섹션에도 찜 여부에 따라 하트 색상이 구분되어 표시된다.
3. "찜" 메뉴를 클릭하면 찜 전용 페이지(`/my/wish`)로 이동하며, "상품"/"작품" 2개 탭으로
   구성되어 있다. "상품" 탭은 2열 그리드 + 무한 스크롤로 찜한 상품을, "작품" 탭은 작품(IP)별
   섹션 + 가로 스크롤 캐러셀로 찜한 상품을 보여준다.
4. "상품" 탭에서는 "편집하기"를 통해 다중 선택 후 일괄 삭제할 수 있으며, "작품" 탭에서는
   섹션 제목 옆 하트 아이콘으로 작품 단위 전체 해제, 또는 캐러셀 내 개별 상품 카드 하트로
   개별 해제가 가능하다. 두 탭의 찜 상태는 서로 동기화된다.
5. 찜한 상품/작품이 없는 경우 각 탭마다 서로 다른 안내 문구의 빈 상태 화면이 노출된다.
6. 비로그인 상태에서 `/my`, `/my/wish` 등에 접근하면 진입 경로(URL 직접 진입 vs 사이트 내
   링크/메뉴 클릭)에 따라 로그인 유도 팝업의 "취소"/로그인 완료 후 동작이 다르게 처리된다.

## 4. Requirements

### 4.1 확인된 요구사항

**진입점 및 기본 찜 처리**
- **REQ-WISHLIST-001**: 찜 아이콘은 메인페이지 상품 카드, 검색페이지 상품 카드, 작품 연관 상품리스트 페이지(`/ip/{id}`) 상품 카드, 내 스토어(`/my`) "찜한 상품"/"최근 본 상품" 섹션 상품 카드, 상품상세 하단 고정 영역 및 "같은 작품 굿즈" 캐러셀(상품상세 PRD에서 기 확인)에 공통으로 노출되며, 클릭 시 동일한 찜 처리 동작(로그인 필요, 토스트 노출, 하트 색상 변경, 토글)이 적용된다.
- **REQ-WISHLIST-002**: 로그인 상태에서만 찜 처리가 가능하며, 비로그인 상태에서 찜 아이콘 클릭 시 로그인 유도 팝업이 노출되고 찜 처리는 되지 않는다. (상품상세 PRD REQ-PRODUCT-DETAIL-033 참조)
- **REQ-WISHLIST-003**: 로그인 상태에서 찜 아이콘 클릭 시 "찜한 상품에 추가했어요" 토스트 노출 및 하트 아이콘이 보라색으로 채워지며, 재클릭 시 찜이 해제되는 토글 방식으로 동작한다. (상품상세 PRD REQ-PRODUCT-DETAIL-034, 048 참조)

**내 스토어(`/my`) 진입점**
- **REQ-WISHLIST-004**: 내 스토어 상단 4개 메뉴 중 "찜" 메뉴에 찜한 상품 개수가 숫자 뱃지로 표시되며, 찜 추가/해제 시 새로고침 없이 즉시 갱신된다.
- **REQ-WISHLIST-005**: "찜한 상품" 섹션(우측 "더보기" 링크)에는 찜한 상품 카드가 나열되며, 각 카드의 찜 아이콘은 보라색(채워짐)으로 표시된다.
- **REQ-WISHLIST-006**: "최근 본 상품" 섹션에는 찜 여부에 따라 하트 아이콘 색상이 구분되어 표시된다(찜한 상품: 보라색 채움 / 찜 안 한 상품: 빈 하트). 판매종료 등 상태의 상품도 함께 노출되며 해당 상태 뱃지가 표시된다.
- **REQ-WISHLIST-007**: "최근 본 상품" 섹션에서 찜 아이콘을 토글하면, 같은 화면의 "찜한 상품" 섹션 및 `/my/wish` 페이지에 새로고침 없이 즉시 반영된다.

**찜 전용 페이지(`/my/wish`)**
- **REQ-WISHLIST-008**: `/my/wish`는 상단에 "상품"/"작품" 2개 탭으로 구성된다.
- **REQ-WISHLIST-009**: "상품" 탭은 2열 그리드로 찜한 상품 카드를 나열하며, 스크롤 시 무한 스크롤 방식으로 추가 항목이 로드된다.
- **REQ-WISHLIST-010**: "상품" 탭 우측 상단에는 "편집하기" 링크가 있으며, "작품" 탭에는 "편집하기" 기능이 없다.
- **REQ-WISHLIST-011**: "작품" 탭은 **작품(IP) 자체를 찜(REQ-WISHLIST-027)한 경우에만** 해당 작품의 섹션이 표시되며(상품 개별 찜 여부와 무관), 각 섹션은 제목(예: "마루는 강쥐 >")과 우측 보라색 하트 아이콘, 그 아래 해당 작품에 속한 상품 중 찜한 상품을 가로 스크롤 캐러셀로 보여준다.
- **REQ-WISHLIST-012**: "작품" 탭 섹션 제목(텍스트/화살표) 클릭 시 해당 작품 페이지로 이동한다.
- **REQ-WISHLIST-013**: "작품" 탭 섹션 제목 우측 하트 아이콘 클릭 시 **해당 작품(IP) 자체의 찜만 해제**되어 섹션이 목록에서 사라진다. 섹션에 속해 있던 개별 상품들의 찜 상태 자체는 영향받지 않고 그대로 유지된다.
- **REQ-WISHLIST-014**: "작품" 탭 캐러셀 내 개별 상품 카드의 하트 아이콘 클릭 시 해당 상품 1개만 찜 해제되며, "상품" 탭에도 동기화되어 즉시 반영된다.
- **REQ-WISHLIST-015**: 판매종료/품절 상태의 상품도 `/my/wish` "상품" 탭에 상태 뱃지와 함께 노출되며, 클릭 시 상품상세 페이지로 정상 진입된다.
- **REQ-WISHLIST-016**: 찜한 상품/작품이 하나도 없는 경우, "상품" 탭에는 "찜한 상품이 아직 없어요." 안내가, "작품" 탭에는 "찜한 작품이 아직 없어요." 안내가 각각 빈 상태 일러스트와 함께 표시된다(탭별로 다른 문구).

**편집 모드("상품" 탭)**
- **REQ-WISHLIST-017**: "편집하기" 클릭 시 편집 모드로 전환되며, 상단에 "전체 선택 (0)" 체크박스와 우측 "선택삭제 · 편집취소" 링크가 나타나고, 각 상품 카드에 선택용 체크 영역이 표시된다.
- **REQ-WISHLIST-018**: "전체 선택" 체크박스 클릭 시 모든 카드가 선택되며(개수 표시 갱신, 카드에 보라색 원형 체크 오버레이), 개별 카드를 클릭하면 개별로 선택/해제할 수 있다.
- **REQ-WISHLIST-019**: "선택삭제" 클릭 시 "삭제하시겠어요? 선택한 상품을 삭제합니다." 확인 팝업(취소/삭제 버튼)이 노출된다. "취소" 클릭 시 팝업만 닫히고 선택 상태/편집 모드가 유지되며, "삭제" 클릭 시 선택된 상품의 찜이 해제된다.
- **REQ-WISHLIST-020**: "편집취소" 클릭 시 편집 모드가 해제되고 일반 찜 화면으로 돌아간다.
- **REQ-WISHLIST-026**: 편집 모드("상품" 탭)에서 선택된 항목이 0건인 상태에서 "선택삭제" 버튼을 클릭하면, 버튼 자체는 비활성화되지 않고 클릭 가능한 상태이지만 클릭해도 아무 반응이 없다(확인 팝업 미노출, 에러 메시지 없음, 삭제 미실행, 화면 변화 없음).
- **REQ-WISHLIST-027**: 작품 페이지(`/ip/{id}`)에는 상품 카드의 찜 아이콘과는 별개로, 작품(IP) 자체를 찜(즐겨찾기)할 수 있는 전용 하트 버튼이 최상단에 존재한다. 이 작품 자체의 찜 여부가 `/my/wish` "작품" 탭에 해당 작품의 섹션이 노출되는지를 결정하며, 이 작품에 속한 개별 상품을 찜하는 것만으로는 "작품" 탭에 섹션이 노출되지 않는다.

**비로그인 접근**
- **REQ-WISHLIST-021**: 비로그인 상태에서 `/my` 페이지 자체는 정상 진입되나, "찜" 메뉴를 클릭하면 `/my/wish` 직접 진입 시와 동일한 로그인 유도 팝업이 노출된다.
- **REQ-WISHLIST-022**: 비로그인 상태에서 `/my/wish` URL로 직접 진입하면 "로그인 후 이용해 주세요." 팝업(배경 미노출, 취소/로그인 버튼)이 노출된다.
- **REQ-WISHLIST-023**: 로그인 유도 팝업의 "취소" 버튼 동작은 진입 경로에 따라 다르다: URL 직접 진입으로 노출된 팝업에서 취소 시 메인페이지로 이동하고, 사이트 내 링크/메뉴 클릭으로 노출된 팝업에서 취소 시 모달만 닫히고 이전 화면이 그대로 유지된다.
- **REQ-WISHLIST-024**: 로그인 유도 팝업의 "로그인" 버튼 클릭 시 라프텔 로그인 페이지(`laftel.net/auth/login?redirect_url=...`)로 이동하며, "이메일로 시작" 버튼과 최근 로그인 수단(카카오/Google/Apple) 아이콘이 노출된다.
- **REQ-WISHLIST-025**: 로그인 완료 후 리디렉션 위치도 진입 경로에 따라 다르다: URL 직접 진입으로 뜬 팝업에서 로그인 완료 시 원래 목적지(`/my/wish`)로 이동하고, 사이트 내 진입점을 통해 이동하다가 뜬 팝업에서 로그인 완료 시 팝업이 뜨기 전 있던 화면으로 이동한다.

### 4.2 미확인 / 추가 확인 필요 항목

- 찜 가능한 상품 개수에 상한선이 있는지는 검증 범위 제외(확인 대상 아님).
- `/my/wish` "상품" 탭 무한 스크롤의 최대 로드 개수 등 스크롤 한계 관련 세부 동작은 검증 범위 제외(확인 대상 아님).

## 5. Feature 단위 In Scope / Out of Scope

**In Scope**
- 찜 아이콘 노출 위치(메인/검색/작품 연관 상품리스트/상품상세/내 스토어) 및 공통 찜 추가/해제 동작
- 내 스토어(`/my`) 진입점(찜 메뉴 뱃지, "찜한 상품"/"최근 본 상품" 섹션의 찜 상태 표시 및 동기화)
- 찜 전용 페이지(`/my/wish`)의 "상품"/"작품" 탭 구성, 목록 노출, 빈 상태
- "작품" 탭의 작품 단위/개별 상품 단위 찜 해제
- "상품" 탭 편집 모드(다중 선택, 선택삭제 확인 팝업, 편집취소)
- 로그인/비로그인에 따른 찜 관련 동작 차이 및 로그인 유도 팝업(취소/로그인 버튼, 진입 경로별 분기)

**Out of Scope**
- 찜 아이콘이 노출되는 각 페이지(메인/검색/작품 연관 상품리스트/상품상세) 자체의 상세 기능(해당 진입점 목적 범위 내에서만 다룸, 별도 Feature PRD에서 다룸)
- 로그인/회원가입 인증 프로세스 자체(라프텔 로그인 페이지 진입 확인까지만 다루며, 이메일/소셜 로그인 처리 자체는 다루지 않음)
- 결제/주문 프로세스

## 6. 예외 / 에러 케이스

- 비로그인 상태에서 찜 아이콘 클릭 시 로그인 유도 팝업, 찜 미처리 (REQ-WISHLIST-002)
- 비로그인 상태에서 `/my` > "찜" 메뉴 클릭 또는 `/my/wish` 직접 진입 시 로그인 유도 팝업 노출, 진입 경로별 "취소"/로그인 완료 후 동작 분기 (REQ-WISHLIST-021~025)
- 판매종료/품절 상품도 찜 목록에 그대로 노출되며 상세 진입은 정상 동작 (REQ-WISHLIST-015)
- 편집 모드에서 "선택삭제" 확인 팝업의 "취소" 선택 시 삭제 미실행, 선택/편집 상태 유지 (REQ-WISHLIST-019)
- 찜한 상품/작품이 없는 경우 탭별로 다른 문구의 빈 상태 화면 노출 (REQ-WISHLIST-016)
- "상품" 탭 편집 모드에서 선택 0건 상태로 "선택삭제" 클릭 시, 버튼은 활성 상태이나 팝업 노출/삭제/화면 변화 없이 아무 반응이 없음 (REQ-WISHLIST-026)

  반영해 최초 승인 시점의 서술(상품 개별 찜을 집계해 작품 탭 섹션을 구성한다는 가정)에서

  노출과 섹션 하트 해제 동작 모두 이 작품 단위 찜 상태를 기준으로 동작한다(사용자 재승인).
