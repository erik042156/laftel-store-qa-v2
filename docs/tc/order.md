# Test Case - 주문

> 이 문서는 `docs/tc/revised6/order.md`(25건)의 `Test Scenario` 컬럼을 `3 Depth`(테스트 시나리오/목적) 컬럼으로 바꾼 새 문서(revised7)다. 3 Depth는 기존 시나리오 문장을 `{검증 대상} {목적 분류}` 형태의 짧은 목적 문구로 다시 쓴 것이며, 이외 컬럼 값(ID, 1·2 Depth, Preconditions, Steps, Expected, Priority, Requirement ID, Result)과 행 순서는 revised6와 동일하다. 대표 TC 참조(괄호)는 3 Depth에 유지했다. 기존 문서·Spreadsheet는 변경하지 않았다.
> 이 문서는 `docs/tc/revised5/order.md`(25건)를 새 TC 컬럼 구조(`ID | 1 Depth | 2 Depth | Test Scenario | Preconditions | Test Steps | Expected Result | Priority | Requirement ID | Result`)로 변환한 새 문서(revised6)다. `Feature` 컬럼을 `1 Depth`(시스템/도메인)와 `2 Depth`(세부 기능/컴포넌트)로 나누고 `Requirement ID`를 Priority 뒤로 옮겼으며, ID·Scenario·Preconditions·Steps·Expected·Priority·Requirement ID·Result 값과 행 순서는 revised5와 동일하다. 기존 문서·Spreadsheet는 변경하지 않았다.
> 본 문서는 `docs/tc/revised4/order.md`(25건)를 tc-writing Skill 1.5(번호 표기 규칙: 복수 항목은 `1.` `2.` 번호와 `<br>` 구분, 단일 항목은 번호 없음)로 재작성한 새 문서이며, 기존 문서(`docs/tc/order.md`, `docs/tc/revised/`~`docs/tc/revised4/order.md`)와 Spreadsheet는 변경하지 않았다. TC의 ID·Requirement ID·Scenario·Priority·내용의 의미·행 구성(25건)은 revised4와 동일하며 번호 표기와 Preconditions의 조건 항목 분리만 변경했다. TC 표는 ID 오름차순이다.
>
> 공통 전제: PC Chrome, Production(https://store.laftel.net/). 모든 TC는 테스트 계정 로그인 상태에서 수행하며 계정 정보는 문서에 기록하지 않는다. Preconditions의 "주문/결제 화면 진입 상태"는 상품상세 "구매하기 > 바로구매" 또는 장바구니 "구매하기"로 `/check-out/{uuid}`에 진입한 상태를 의미하며, 진입 경로가 검증 대상인 TC만 경로를 명시한다. Test Steps에는 해당 TC의 사용자 동작 1개만 쓰고, 이전 진입·입력·상태는 Preconditions에 쓴다.
> 검증 범위 제한: 본 문서는 주문/결제 화면(`/check-out/{uuid}`) 진입부터 PG 결제창 노출까지만 다룬다. 실제 결제 승인·주문 완료, 주문내역, 주문 취소, 1:1 문의, 쿠폰 적용(적용 가능 쿠폰이 있는 케이스)은 PRD Out of Scope/QA plan 검증 제외 범위이므로 TC로 만들지 않았다. PG 결제창이 노출되면 결제 수단 입력·결제 진행 없이 창을 닫는다.
> Production 데이터 주의: 주문/결제 화면 진입 시 Production 계정에 주문서(`/check-out/{uuid}`)가 생성될 수 있으며, 장바구니 담기·바로구매 진입이 필요한 TC는 장바구니/주문서 데이터를 생성·변경할 수 있다. 해당 TC(TC-ORDER-001, 002, 005, 013, 014, 017, 021, 022)는 Preconditions에 `[Production 데이터 변경]` 계열로 표기했으며, 그 외 TC도 주문/결제 화면 진입 단계에서 동일하게 주문서가 생성될 수 있으므로 수행 전 사용자 승인이 필요하다(CLAUDE.md 11절). 수행 후 테스트로 담은 장바구니 상품은 정리한다.
> 연계 참조(다른 Feature 대표 TC): 상품상세 "구매하기" 확장 영역 UI 자체는 TC-PRODUCT-DETAIL-031/032, 장바구니 화면의 결제금액·"구매하기 (N)" 버튼은 TC-CART-020/021, 장바구니 선택 0건 "구매하기" 차단은 TC-CART-017에서 검증한다. 본 문서는 주문/결제 화면 기준으로만 검증한다.
> Risk 참조: Risk 스프레드시트의 `리스크 매트릭스`(RI-ORDER-001~006, Likelihood/Impact/Risk Score 확정값)를 읽기 전용으로 참조했다(revised 문서에서 확인한 값을 그대로 사용).
